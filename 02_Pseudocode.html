Pseudocode

Warum Pseudocode?

Quelle: susan-lu4esm auf pixabay

In Kochrezepten steht nie:

for(i=0; i<2; i++) {
   add(egg);
}

Sondern: Zwei Eier hinzufügen

Pseudocode ist genau das:
Kochen ohne Grammatikprüfung.

Aufschreiben, was passieren soll -
egal, wie die Programmiersprache es genau formuliert.

WENN-Struktur

Minimal

WENN bedingung DANN
    anweisungen
ENDE WENN

Beispiel

WENN Benutzername ist leer DANN
    AUSGABE "Bitte Namen eingeben."
ENDE WENN

Alternativ-Bedingung

WENN bedingung DANN
    anweisungen
SONST WENN andere_bedingung DANN
    anweisungen
ENDE WENN

Beispiel

WENN Punktzahl ≥ 92 DANN
    AUSGABE "Hervorragend"
SONST WENN Punktzahl ≥ 81
    AUSGABE "Gut!"
ENDE WENN

WENN: Alternativ-Bedingungen

Alternativ-Bedingungen

WENN bedingung DANN
    anweisungen
SONST WENN andere_bedingung DANN
    anweisungen
SONST
    anweisungen
ENDE WENN

Beispiel

WENN Punktzahl ≥ 81 DANN
    AUSGABE "Gut!"
SONST WENN Punktzahl ≥ 50 DANN
    AUSGABE "Geschafft!"
SONST
    AUSGABE "Dann eben Nachprüfung."
ENDE WENN
  • DANN ist Pflicht.
  • SONST WENN wird ausgeschrieben (nicht etwa ELSE IF).
  • ENDE WENN ist Pflicht - auch bei kurzen Blöcken!

IHK-Prüfungsfallen

  • Fehlende Blockenden
    ENDE WENN, ENDE FUER, ENDE SOLANGE,
    ENDE METHODE

  • Falsche Operatoren
    = Zuweisung
    == Vergleich

  • Keine Englischsprachigen Keywords
    KEIN if, else, while, for, return

  • Keine Klammern
    { } nicht verwenden
    Keine ( ) bei Kontrollstrukturen

IHK Stilregeln

  • Einrückung empfohlen
  • Schlüsselwörter GROß schreiben
  • Variablennamen klein schreiben
  • keine unnötigen Leerzeilen
  • Kommentare sparsam einsetzen
  • keine Sprache nachahmen!
    (kein Python-Stil, kein Java-Stil)
